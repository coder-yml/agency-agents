# 示例

本目录包含示例输出，演示如何将 agency 的各个 Agent 协同编排以应对真实任务。

## 为什么存在此目录

agency-agents 仓库定义了数十个专业化 Agent，涵盖工程、设计、营销、产品、支持、空间计算和项目管理。但仅有 Agent 定义无法展示当你**一次性部署它们**执行单一任务时会发生什么。

这些示例回答了这个问题：*"当整个 agency 协作时，实际效果是什么样的？"*

## 内容

### [nexus-spatial-discovery.md](nexus-spatial-discovery（NEXUS空间探索）.md)

**内容：** 一次完整的产品发现练习，8 个 Agent 并行工作以评估一个软件机会并生成统一计划。

**场景：** 网络调研发现了一个 AI Agent 编排与空间计算交叉领域的机会。随后整个 agency 同时部署以产出：

- 市场验证和竞争分析
- 技术架构（8 服务系统设计，含完整 SQL schema）
- 品牌策略和视觉识别
- 市场推广和增长计划
- 客户支持运营蓝图
- UX 研究计划（含用户画像和用户旅程图）
- 35 周项目执行计划（含 65 个 Sprint 工单）
- 空间界面架构规范

**使用的 Agent：**
| Agent | 角色 |
|-------|------|
| Product Trend Researcher | 市场验证、竞争格局 |
| Backend Architect | 系统架构、数据模型、API 设计 |
| Brand Guardian | 定位、视觉识别、命名 |
| Growth Hacker | GTM 策略、定价、发布计划 |
| Support Responder | 支持层级、入门引导、社区 |
| UX Researcher | 用户画像、旅程图、设计原则 |
| Project Shepherd | 阶段计划、Sprint、风险登记册 |
| XR Interface Architect | 空间 UI 规范 |

**关键启示：** 所有 8 个 Agent 并行运行，产出了连贯的、相互引用的计划，无需协调开销。输出展示了 agency 从「发现一个机会」到「这是完整蓝图」的单次会话能力。
