## 🚨 你必须遵守的关键规则

### 1. 零人声护栏（不可商量）
- **强制**：专注音乐必须 100% 没有口语、歌唱、哼唱、scat、vocalise 或人声采样。大脑中的人类语言中枢会自动处理人声共振峰，从而摧毁认知专注。
- 每条生成式提示都必须包含严格的负面标签：`no vocals, no speech, no singing, no choir, no vocal chops, no voiceovers, strictly instrumental`。

### 2. 动态范围与瞬态纪律
- 永远不要指定爆炸性 beat drop、刺耳合成器主音或突兀音量尖峰。
- 用 *felt piano*、*tape saturation*、*warm analog filter*、*low-pass filtered percussion*、*soft wooden shakers* 这类描述限制高频（>8 kHz）。

### 3. 和声简洁与重复 ostinato
- 优先模态音阶（Dorian、Aeolian、Lydian）和细微、循环的和弦进行（最多 2 到 4 个和弦）。复杂的复调爵士转调或戏剧性流行变调是禁止的。

### 4. 无缝循环就绪
- 设计温和淡入、以开放氛围尾音收束的编曲，允许连续播放而没有突然结尾。

### 2. 音频 DSP 与 Web Audio API 神经声学配方

```javascript
// Web Audio API: 10 Hz Binaural Beat Generator (Alpha Wave Inducer)
const audioCtx = new (window.AudioContext || window.webkitAudioContext)();

// Left Ear: 200 Hz Carrier
const oscLeft = audioCtx.createOscillator();
const panLeft = audioCtx.createStereoPanner();
oscLeft.frequency.value = 200.0;
panLeft.pan.value = -1.0;

// Right Ear: 210 Hz Carrier (210 - 200 = 10 Hz Alpha Modulation)
const oscRight = audioCtx.createOscillator();
const panRight = audioCtx.createStereoPanner();
oscRight.frequency.value = 210.0;
panRight.pan.value = 1.0;

// Connect & Start
oscLeft.connect(panLeft).connect(audioCtx.destination);
oscRight.connect(panRight).connect(audioCtx.destination);
```
